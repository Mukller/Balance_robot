```cpp
// В том месте где считается PID для баланса и скорости
void controlLoop() {
  float dt = (timer_value - timer_old) / 1000000.0;
  
  // === СУЩЕСТВУЮЩИЙ КОД ===
  float balance_output = stabilityPDControl(dt, angle_adjusted, target_angle, Kp, Kd);
  float speed_output = speedPIControl(dt, actual_robot_speed, throttle, Kp_thr, Ki_thr);
  // ========================
  
  control_output = balance_output + speed_output;
  
  // === ДОБАВИТЬ ЭТО ===
  if (line_mode != LINE_MODE_OFF) {
    int16_t line_steering = LineFollower_getSteering();
    steering += (line_steering * 0.3);  // 0.3 = вес влияния
    steering = constrain(steering, -max_steering, max_steering);
  }
  // ====================
  
  // Отправить на моторы
  setMotorSpeedM1(control_output - steering);
  setMotorSpeedM2(control_output + steering);
}
```

## 🎮 Управление

### Через Serial Monitor:
```
Команда: line_mode 0  → OFF (отключить)
Команда: line_mode 1  → ON (включить)
Команда: line_mode 2  → AUTO (умный режим)
```

### Через Wi-Fi:
```
http://192.168.X.X/line?mode=0    → OFF
http://192.168.X.X/line?mode=1    → ON
http://192.168.X.X/line?mode=2    → AUTO
http://192.168.X.X/line?calib=1   → Калибровка
```

### Отладка:
```
Команда: line_debug → вывести значения датчиков
```

## 📊 Пример Serial Output

```
[LineFollower] Initialized - 5 sensor array
[LineFollower] Run calibration before use!

[Line] Raw: 450 780 3200 950 400 | Cal: 12 34 198 45 11 | Error: 145 | Steering: 72
```

**Значения:**
- **Raw**: исходные АДЦ (0-4095)
- **Cal**: нормализованные (0-200, где 200=черный)
- **Error**: смещение линии (-200 влево, +200 вправо)
- **Steering**: команда для поворота

## ⚙️ Первая настройка

### Начать с этих значений:
```cpp
// В LineFollower.cpp
float Kp_line = 0.5;  // Чувствительность

// В main sketch (контроль loop)
steering += (line_steering * 0.3);  // 0.3 = вес влияния
```

### Если робот не следит за линией:
```cpp
// Вариант 1: Увеличить агрессивность
Kp_line = 0.7;        // Было 0.5
steering += ... * 0.4  // Было 0.3
```

### Если робот теряет баланс:
```cpp
// Вариант 2: Снизить влияние линии
steering += (line_steering * 0.2);  // Было 0.3
Kp_line = 0.3;                      // Было 0.5
```

### Этап 2: Статический баланс
- Отключить линию-следование (mode=0)
- Включить робот
- Убедиться что балансирует нормально

### Этап 3: Динамический баланс
- Включить режим OFF (mode=0)
- Медленно ездить по белой поверхности
- Убедиться что движение нормальное

### Этап 4: Линия-следование
- Включить режим ON (mode=1)
- Разместить над чёрной линией
- Медленно двигать линию из стороны в сторону
- Робот должен поворачивать за ней

### Этап 5: Оптимизация
- Увеличивать скорость
- Менять Kp_line и weight для оптимума
- Протестировать на разных линиях (разные углы, радиусы)

## 💡 Тонкая настройка

### Таблица параметров:

| Поведение | Проблема | Решение |
|-----------|----------|---------|
| Не следит | Слишком инертный | ↑ `Kp_line` (0.5→0.7) |
| Теряет баланс | Слишком агрессивный | ↓ `Kp_line` (0.5→0.3) |
| Осциллирует | Переколебания | ↓ `Kp_line` или ↓ `weight` |
| Неточно | Дрейфит | Повторить калибровку |
| На быстрой скорости дёргается | Слишком активно | ↓ `weight` (0.3→0.2) |

## 🆘 Если что-то не работает

### Датчик не инициализируется
```
❌ [LineFollower] Failed to initialize
→ Проверить GPIO пины (должны быть 34, 35, 36, 39, 32)
→ Проверить питание 5V
```

### Значения датчика все одинаковые
```
❌ All sensors: 4095
→ Проверить подключение VCC
→ Проверить АДЦ конфигурацию
```

### Калибровка не работает
```
❌ Calibration failed
→ Убедиться что датчик полностью над белым/чёрным
→ Проверить освещение
→ Повторить калибровку
```

### Робот не выполняет команды
```
❌ Mode not changing
→ Проверить код в main sketch (правильно ли добавлен?)
→ Убедиться что line_mode переменная объявлена
```
